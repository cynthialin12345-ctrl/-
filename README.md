# 🎓 元智大學資訊管理學系資料庫專案：學籍成績管理系統

本專案為元智大學資訊管理學系資料庫課程專案。系統整合了完整的學生學籍 CRUD、Offset-Fetch 分頁、模糊搜尋，以及基於 FastReport 的歷年成績單 PDF 一鍵生成功能。介面採用現代暗色毛玻璃（Glassmorphism）風格，並基於 Tailwind CSS 進行全響應式版面規劃，精簡了花哨特效，回歸專業流暢的商務感。

## 📄 第三步：如何「產生成績單 PDF」

1. 點擊頂部導覽列的 **「產生成績單」**。
2. **選取學生**：在下拉式選單中選擇您想產生成績單的在學學生。
3. **一鍵下載**：點擊 **「產生並下載歷年成績單」**。
4. **成果展示**：系統會呼叫 FastReport 報表引擎，即時下載一份高畫質的 PDF 歷年成績單。成績單中包含**元智大學校徽浮水印、註冊組戳章、教務長簽名章**，學分與學位對應完全符合規範！

## 🎓 第四步：如何「管理與編輯學生」（學籍 CRUD + 分頁）

點擊頂部導覽列的 **「編輯學生」**，即可進入全功能學籍管理中心：

1. **搜尋學生**：在上方搜尋欄輸入「學號」或「姓名」關鍵字，即可即時過濾名單。
2. **分頁瀏覽**：列表底部提供「上一頁 / 下一頁」分頁按鈕（每頁顯示 `5` 筆，操作極度流暢）。
3. **註冊新學籍 (Create)**：
   *   在左側「註冊新學籍」表單輸入：**學號、系所代碼（資管系請填 `502`）、姓名、入學學年度、畢業學年度（可選）**。
   *   點擊 **「註冊學籍」** 即可存入資料庫。
4. **彈窗編輯 (Update)**：
   *   在名冊列表中，點擊您想修改的學生右側的 **「編輯」** 按鈕。
   *   網頁會滑順地彈出一個毛玻璃編輯視窗，直接在視窗中修改姓名或科系，點擊 **「儲存變更」**，名冊立刻動態更新！
5. **安全級聯刪除 (Delete)**：
   *   點擊列表右側的 **「刪除」** 按鈕。
   *   系統會跳出警告 Modal，點擊確認後，系統會透過 **資料庫交易（Transaction）** 技術，自動清除該生的修課歷史、學期成績、累計統計，最後乾淨刪除學生，**絕對不會產生資料庫外鍵約束衝突**！

## 📝 第五步：如何「登錄修課成績」

點擊頂部導覽列的 **「修課成績」**：

1. **登記成績**：
   *   **選取學生**：下拉式選單選擇學生。
   *   **選取課程**：下拉選單已 100% 對齊您提供的 YZU IM 114學年度科目表（如：`IM208` 資料庫管理、`IM244` 生成式人工智慧之商業應用...等共 93 門 YZU 正式科目）。
   *   **學期資訊**：填入課業學年度與學期。
   *   **輸入分數**：填入成績分數後，點擊 **「送出登記」**。
2. **查看與刪除已修科目**：
   *   在下方「選取學生查看已修科目」中挑選學生。
   *   下方會以漂亮的表格即時顯示該生**目前所有登錄的科目、學分與分數**。
   *   如果您發現登記錯誤，直接點擊該科目右側的 **「刪除」**，即可在不刷新整頁的情況下，將該筆成績無痛移除！
